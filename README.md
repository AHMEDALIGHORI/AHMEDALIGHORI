### 01 · Voice2Law — bilingual legal information for Pakistan

<p align="left">
  <img src="https://img.shields.io/badge/STATUS-active-0F6B52?style=flat-square&labelColor=10100F" alt="Active">
  <img src="https://img.shields.io/badge/URDU%20%2B%20ENGLISH-voice%20and%20text-D7FF3F?style=flat-square&labelColor=10100F" alt="Urdu and English, voice and text">

Ask a legal question in **Urdu or English**, by voice or text, and get an answer grounded in a **governed corpus of Pakistani law** with source citations — then export a structured, lawyer-ready case handoff. It is the largest thing in this account: **1,241 files** across a React 18 client and a Python NLP service.

- **Client** — React 18, TypeScript, Vite, Firebase auth, responsive and keyboard-accessible
- **Service** — FastAPI NLP service with its own test package
- **Quality gates** — `typecheck → build → bundle budget` scripted, tests on both sides of the stack, Dependabot PRs
- **Ship path** — Docker, PM2 auto-start, and documented AWS and Azure deployments

### 02 · Noor Islamic Companion — answers that cite their sources

<p align="left">
  <img src="https://img.shields.io/badge/SOURCES-28%20verified%20records-0F6B52?style=flat-square&labelColor=10100F" alt="28 verified source records">
  <img src="https://img.shields.io/badge/RAG-multilingual-D7FF3F?style=flat-square&labelColor=10100F" alt="Multilingual RAG">
  <img src="https://img.shields.io/github/license/AHMEDALIGHORI/noor-islamic-companion?style=flat-square&labelColor=10100F&color=D7FF3F" alt="MIT licence">
  <img src="https://img.shields.io/github/last-commit/AHMEDALIGHORI/noor-islamic-companion?style=flat-square&labelColor=10100F&color=EF4D2F" alt="Last commit">
</p>

Most AI chatbots hallucinate religious citations. Noor retrieves **verified Quran, Hadith, and Tafsir passages first**, then generates only from what it retrieved — returning exact references, relevance scores, and retrieval metadata. It refuses to present itself as a mufti and routes high-stakes questions to qualified scholars.

- **Retrieval** — `paraphrase-multilingual-MiniLM-L12-v2` embeddings, cosine similarity over pre-cached sources, lexical fallback, hybrid ranking, 8-second retrieval timeout
- **Stack** — React Native + Expo Router, tRPC, Drizzle + MySQL, Zod, NativeWind, Hugging Face Inference Providers
- **Process** — source-contribution issue templates, source research notes, documented methodology

## 🧭 Architecture

Two request paths I designed end to end — drawn as plain SVG so they render everywhere, at any zoom, without a third-party service in the middle.

<p align="center">
  <img src="./assets/arch-voice2law.svg" alt="Voice2Law request path: voice or text input, FastAPI NLP service, governed corpus of Pakistani law, cited answer, lawyer-ready case handoff" width="100%">
</p>

<p align="center">
  <img src="./assets/arch-noor-rag.svg" alt="Noor retrieval path: question in English or Urdu, multilingual embedding, cosine search over cached source vectors, hybrid ranking, top-8 passages in the prompt, cited answer with relevance scores" width="100%">

<table>
<tr>
<td width="50%" valign="top">

**Grounding is the feature, not the wrapper**

In both systems the retrieval layer decides what the model is allowed to say. Noor ranks retrieved passages and injects the top eight; Voice2Law answers from a governed corpus and attaches its citations. If the sources are wrong, the answer is wrong — so the sources are the part worth engineering.

</td>
<td width="50%" valign="top">

**Boring, inspectable infrastructure**

One dependency in the RAG starter, zero in the Quran client. Small surfaces are easy to test, easy to audit, and hard to break by accident. The same instinct shows up in the client work: one Next.js foundation, ten deliveries, no ten codebases.

</td>
</tr>

## 🧠 How I work

- **Grounding over guessing.** If a system cannot show where an answer came from, it is not finished.
- **Measure, then claim.** Typechecks, test suites, and bundle budgets live in repo scripts, not in prose.
- **One foundation, many ships.** A reusable baseline beats ten bespoke codebases — ten client sites prove it.
- **Accessibility is part of the brief.** Keyboard paths, contrast, and reduced-motion handling are engineering decisions, not a follow-up ticket.

**Open-source focus:** multilingual citation-aware retrieval · TypeScript packages with no dependency drag · interfaces that make complex systems feel simple · documentation that respects the reader's time.
