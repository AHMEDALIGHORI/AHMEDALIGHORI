### 01 · Voice2Law — bilingual legal Q&A grounded in real Pakistani law

<img src="https://img.shields.io/github/last-commit/AHMEDALIGHORI/Voice2Law-Website?style=flat-square&color=D7FF3F" alt="Voice2Law last commit"> <img src="https://img.shields.io/badge/files-1%2C241-EF4D2F?style=flat-square" alt="File count"> <img src="https://img.shields.io/badge/React_18-D7FF3F?style=flat-square" alt="React 18"> <img src="https://img.shields.io/badge/FastAPI-EF4D2F?style=flat-square" alt="FastAPI">

Ask a legal question in **Urdu or English**, by voice or text, and get an answer grounded in a **governed corpus of Pakistani law** with source citations — then export a structured, lawyer-ready case handoff.

- **Client** — React 18, TypeScript, Vite, Firebase auth, responsive and keyboard-accessible
- **Service** — FastAPI NLP service with its own test package
- **Quality gates** — `typecheck → build → bundle budget` scripted, tests on both sides of the stack, Dependabot PRs
- **Ship path** — Docker, PM2 auto-start, and documented AWS and Azure deployments

**Try it:** [Source](https://github.com/AHMEDALIGHORI/Voice2Law-Website)

### 02 · Noor Islamic Companion — answers that cite their sources

<img src="https://img.shields.io/badge/sources-28%20verified%20records-0F6B52?style=flat-square&labelColor=10100F" alt="28 verified source records"> <img src="https://img.shields.io/badge/RAG-multilingual-D7FF3F?style=flat-square&labelColor=10100F" alt="Multilingual RAG"> <img src="https://img.shields.io/github/license/AHMEDALIGHORI/noor-islamic-companion?style=flat-square&labelColor=10100F&color=D7FF3F" alt="MIT licence"> <img src="https://img.shields.io/github/last-commit/AHMEDALIGHORI/noor-islamic-companion?style=flat-square&labelColor=10100F&color=EF4D2F" alt="Last commit">

Most AI chatbots hallucinate religious citations. Noor retrieves **verified Quran, Hadith, and Tafsir passages first**, then generates only from what it retrieved — returning exact references, relevance scores, and retrieval metadata. It refuses to present itself as a mufti and routes high-stakes questions to qualified scholars.

- **Retrieval** — `paraphrase-multilingual-MiniLM-L12-v2` embeddings, cosine similarity over pre-cached sources, lexical fallback, hybrid ranking, 8-second retrieval timeout
- **Stack** — React Native + Expo Router, tRPC, Drizzle + MySQL, Zod, NativeWind, Hugging Face Inference Providers
- **Process** — source-contribution issue templates, source research notes, documented methodology

**Try it:** [Source](https://github.com/AHMEDALIGHORI/noor-islamic-companion)

## 🏗️ Architecture

Two request paths I designed end to end — drawn as plain SVG so they render everywhere, at any zoom, without a third-party service in the middle.

<img src="./assets/arch-voice2law.svg" alt="Voice2Law request path: question in Urdu or English, transcription, retrieval over the governed legal corpus, grounded answer with citations, then lawyer-ready handoff" width="100%">

<img src="./assets/arch-noor-rag.svg" alt="Noor retrieval path: multilingual query, embeddings, cosine similarity over pre-cached verified sources, hybrid ranking, then a cited answer" width="100%">

| Design decision | Why it holds |
| --- | --- |
| **Retrieve before generating** | Noor never writes a citation it has not retrieved, which is the difference between an answer and a guess. |
| **Sources as data, not prompts** | Keeping the corpus versioned and reviewable means a wrong claim is a data fix, not a prompt-engineering problem. |
| **Graceful degradation** | An 8-second retrieval timeout with a lexical fallback means a slow or missing embedding service still returns an answer. |
| **Bilingual from the first commit** | Urdu and English are handled in the type signatures and the schema, not bolted on by string replacement later. |

## 🧠 How I work

- **Evidence over assertion.** A tool that cannot show why it produced an answer is not finished. Every claim carries the passage it came from.
- **Retrieve before generating.** A citation that was not retrieved is a guess wearing a footnote. The corpus comes first, the model second.
- **Build the boring parts properly.** Typed responses, tests on both sides of the stack, and a scripted `typecheck → build → bundle budget` gate, because that is what keeps a project maintainable after the demo.
- **Ship the whole path.** Docker, documented deploys, and an accessible keyboard-navigable interface — a feature nobody can install is not a feature.
- **Open by default.** MIT licensing, documented methodology, and contribution templates, so the work outlives the person who wrote it.

**Focus:** retrieval-grounded AI · bilingual NLP · immersive frontend · developer tools that are small enough to read in one sitting.
